=== HOW TO ADD YOUR 2D ASSETS (IMAGES & SPRITES) ===

Yahan aap apni images (.png, .jpg) add kar sakte hain. Game automatically ya custom image name se load karega:

1. PLAYER SPRITE:
   - File Name: player.png (Recommended 96x110 px transparent PNG)
   - Agar aap spritesheet use karna chahein toh run/jump frames add kar sakte hain.

2. MONSTER / ENEMY SPRITE:
   - File Name: monster.png (Indian Asura / Demon themed)

3. CUSTOM BACKGROUND:
   - File Name: background.png (1920x1080 ya 1280x720)

Note: Jab tak aap files add nahi karte, game me Silksong-level Indian themed procedural graphics automatically render ho rahe hain!

==================================================================
Custom 2D Assets Kaise Add Karein?

Aap jab chahein apne khud ke designs drop kar sakte hain:

assets/images/player.png → Aapka custom 2D player character sprite.
assets/images/monster.png → Aapka custom 2D monster sprite.
assets/images/background.png → Custom background image.
assets/audio/ → Real MP3/WAV music aur sounds.

(Jab tak aap files nahi daalte, tab tak game ke internal procedural high-level graphics aur sounds automatically chalenge!)
